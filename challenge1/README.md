# Challenge 1 — Menu Driven DevOps Tool

## Description
A bash script that provides a menu-driven interface to perform common DevOps tasks.

## Features
- Check CPU usage
- Check RAM usage
- Restart nginx
- Backup logs
- Exit

## How to Run
```bash
chmod +x devops_menu.sh
./devops_menu.sh
```
