# Linux Automation Lab

## Objective

This project demonstrates a DevOps deployment automation script using Bash.

The script:
- Pulls latest code
- Clears cache
- Restarts application
- Verifies service health

## Project Structure

linux-automation-labs/
├── README.md
├── scripts/
│   └── deploy.sh
└── screenshots/

## How to Run

chmod +x scripts/deploy.sh

./scripts/deploy.sh
